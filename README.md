# forkop-rules

Отредактируйте `domains.lst`, затем запустите **update.bat** двойным щелчком.
Окно останется открытым с результатом. Из терминала или в Linux можно запустить:

```bash
node update.mjs
```

Нужны Node.js 22+, Git и OpenSSH (`ssh`). Установка npm-пакетов не требуется.
Скрипт создаёт коммит только изменённых `.lst`, делает push текущей ветки, ждёт
обновления GitHub Raw и запускает штатное обновление списков Forkop на роутере.
Дополнительного перезапуска VPN и обновления самого Forkop нет.

Роутер по умолчанию: `root@192.168.0.1:22`. Пароль скрыто запрашивает OpenSSH;
существующие SSH-ключи и агент тоже работают. Host key должен уже быть проверен
и сохранён в обычном `known_hosts`; неизвестный/изменившийся ключ блокирует вход.
Пароль скрипт не сохраняет. Адрес и ключ при необходимости задаются переменными
`ROUTER_HOST`, `ROUTER_PORT`, `ROUTER_USER`, `ROUTER_SSH_KEY`; remote — `GITHUB_REMOTE`.

В Forkop должен быть подключён Raw URL списка:

```text
https://raw.githubusercontent.com/000Ren000/forkop-rules/main/domains.lst
```

Для Forkop 2 используется `forkop clash_api PUT /providers/rules` с проверкой
SSH exit code и HTTP status ответа. Для старой версии — `forkop list_update`,
если она есть в справке. Проверяется ответ штатной команды, без проверки трафика.
Уже существующие локальные коммиты текущей ветки также попадут в обычный push.

Посмотреть действия без изменений и подключений:

```bash
node update.mjs --dry-run
```

В Windows также можно выполнить `update.bat --dry-run`.

При ошибке push SSH не запускается. При задержке Raw или ошибке SSH повторите
запуск после устранения причины. Таймаут SSH — 3 минуты; удалённая операция после
обрыва может продолжить работу, сначала проверьте её состояние.
